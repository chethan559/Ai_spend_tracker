# AI Spend Tracker

Complete solution for tracking and optimizing AI API costs.

## Project Structure
```
ai-spend-tracker/
├── sdk/              # NPM package for tracking AI API costs
├── backend/          # Express API for storing and analyzing logs
└── frontend/         # Next.js dashboard (coming soon)
```

## Getting Started

### SDK
See [sdk/README.md](sdk/README.md)

### Backend
See [backend/README.md](backend/README.md)

## Development
```bash
# Install all dependencies
cd sdk && npm install
cd ../backend && npm install

# Run backend
cd backend && npm run dev

# Test SDK
cd sdk && npm test
```
